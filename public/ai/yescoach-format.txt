# YesCoach program format

You are writing a workout program that the user will import into the YesCoach app (Android).
Follow every rule in this file. The app rejects the whole file if any rule is broken.

## What to give the user

1. Ask about anything you need first: goal, days per week, session length, equipment, experience, injuries.
2. Produce ONE JSON file named after the program, for example upper-lower-4-day.json.
   Offer it as a downloadable file. If you cannot create files, put the JSON in a single code block
   and tell the user to save it as a .json file.
3. JSON only inside the file: no comments, no trailing commas, no text before or after.
4. After the file, tell the user how to import it:
   Open YesCoach > Plan tab (with no workout in progress) > Programs icon at the top > Import (download arrow) > pick the file.

## File structure

{
  "version": "1.0",
  "type": "yescoach_program",
  "program": {
    "name": "Upper Lower 4-Day",
    "description": "Optional, one or two sentences.",
    "category": "training",
    "frequency": "4 days/week",
    "days": [
      {
        "name": "Upper A",
        "exercises": [
          {
            "exerciseId": "bench_press:flat:barbell:none",
            "exerciseName": "Barbell Flat Bench Press",
            "sets": 3,
            "reps": "6-8",
            "suggestedRIR": 2,
            "notes": "Optional coaching cue."
          }
        ]
      }
    ]
  }
}

## Rules

- version: exactly "1.0". type: exactly "yescoach_program".
- program.name: 1 to 100 characters.
- program.category (optional): "training" for strength programs, "protocol" for mobility or rehab routines.
- program.frequency (optional): short text, for example "3 days/week", "3-4x/week", "Daily".
- days: one entry per session, in order. Day name: 1 to 50 characters.
- Multi-week plans: the format has no weeks level. For a plan that changes week to week, write every
  week's sessions as their own days, prefixed with the week: "W1 Upper A", "W1 Lower A", "W2 Upper A", ...
  Put each week's sets, reps and RIR on its own days, and tell the user the plan runs in order, one day per session.
  For a plan that repeats the same week, write that one week only.
- exerciseId: MUST be copied exactly from the exercise list below. Never invent or edit an ID.
  If the exercise the user wants is not in the list, pick the closest listed exercise and say which substitution you made.
- exerciseName: copy the name from the same line of the list.
- sets: whole number from 1 to 20.
- reps: text in one of these forms only: "8", "8-10", "30s", "30-60s", "10/side", "8-10/leg", "30s/side".
  No words like "AMRAP" or "to failure". Use seconds ("45s") for holds and stretches.
- suggestedRIR: whole number from 0 to 10 (reps in reserve: how many more reps the user could have done).
  Typical: 1-3 for strength work, 3-4 for beginners, 0 only for isolation finishers.
- notes (optional): a short cue.
